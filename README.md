# 赫韵白加黑防脱密发护理组合 - 产品故事页

基于 Vite 构建的静态产品展示页，已部署到 GitHub Pages。

## 在线地址

https://cmz189.github.io/my-website/

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物输出到 `dist/`，GitHub Pages 从 `gh-pages` 分支根目录发布。

## 说明

- 页面中的“头皮测评 / AI 海报”功能依赖本地 Node 后端（`server.mjs`），GitHub Pages 仅托管静态文件，因此该功能在线不可用。
